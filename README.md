# Shivani Sharma Portfolio

This is a frontend-only Vite portfolio. It showcases my projects, skills, certificates, resume, and contact details without a backend server or database.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. Run `npm install`.
3. Run `npm run dev` and open `http://localhost:5173`.
4. Run `npm run build` to generate the production bundle in `dist/`.
5. Run `npm start` to preview the production build locally.

## Deploy

- Netlify: import the repository and publish the `dist/` folder after `npm run build`.
- GitHub Pages or any static host: deploy the generated `dist/` output.

Contact is handled through direct email, phone, LinkedIn, and GitHub links. The portfolio does not collect or store messages.

The supplied resume and certificate PDFs are served as static files from `public/assets/`. Coursera certificate cards also link to their official verification pages.
